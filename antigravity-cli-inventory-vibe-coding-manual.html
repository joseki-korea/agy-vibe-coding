운영체제별 필수 설치 프로그램 명령어 (Node.js & Git)

macOS (MacBook) 환경 세팅

터미널(Terminal) 앱을 열고 아래 명령어를 순서대로 실행합니다.

1. Homebrew 및 Node.js 설치
zsh
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew install node git gh
Windows (PC) 환경 세팅

PowerShell을 '관리자 권한으로 실행'하여 아래 명령어를 입력합니다.

1. winget으로 Node.js 및 Git 설치
PowerShell
winget install OpenJS.NodeJS
winget install Git.Git
winget install GitHub.cli

Step 1. Antigravity CLI 설치 & 구글 로그인

macOS
zsh
# 글로벌 CLI 설치
npm install -g agy

# 로그인 (브라우저 승인)
agy login
Windows
PowerShell
# 스크립트 실행 권한 허용 (최초 1회)
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

# 글로벌 CLI 설치 & 로그인
npm install -g agy
agy login

Step 3. 작업 폴더 이동 & 로컬 앱 생성

macOS 작업 폴더 생성을 위한 터미널 명령어
zsh
mkdir -p ~/orca/vibe-inventory
cd ~/orca/vibe-inventory
touch .env.local
Windows 작업 폴더 생성을 위한 PowerShell 명령어
PowerShell
New-Item -Path "$HOME\orca\vibe-inventory" -ItemType Directory -Force
Set-Location "$HOME\orca\vibe-inventory"
New-Item -Path .env.local -ItemType File
4

Step 4. Supabase 연동 & `.env.local` 세팅

`.env.local` 파일 내용 (OS 공통)

`.env.local` 파일을 열고 Supabase 대시보드에서 가져온 주소와 키를 입력합니다.

.env.local
VITE_SUPABASE_URL=https://apwjwaryrlpqmdabilvu.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6...your-anon-key...

Step 5. Cloudflare Pages 프로덕션 무료 배포

macOS 배포 명령어
zsh
# 빌드 검증
npm run build

# Cloudflare CLI 로그인 & 배포
npx wrangler login
npx wrangler pages project create vibe-inventory --production-branch main
npx wrangler pages deploy ./dist --project-name=vibe-inventory
Windows 배포 명령어
PowerShell
# 빌드 검증
npm run build

# Cloudflare CLI 로그인 & 배포
npx wrangler login
npx wrangler pages project create vibe-inventory --production-branch main
npx wrangler pages deploy ./dist --project-name=vibe-inventory

✨ 배포 성공 최종 URL: https://vibe-inventory.pages.dev (PC & 모바일 공통 접속)
