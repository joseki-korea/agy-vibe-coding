비개발자를 위한 핵심 인증 용어 1분 정리

개발을 몰라도 이 4가지 개념만 이해하면 세상의 모든 서버리스 앱을 만들 수 있습니다.

PAT (Personal Access Token)
아이디/비밀번호 대신 사용하는 '컴퓨터 전용 신분증'입니다. 안티그래비티 CLI가 내 GitHub 계정을 대신해서 소스코드를 저장소에 올릴 때 사용합니다.
예시: ghp_a1b2c3d4e5...
보안등급: 최고 보안 (유출금지)
Anon Key vs Service Role Key
Supabase 데이터베이스에 들어갈 수 있는 '출입증'입니다.
· Anon Key: 손님용 (브라우저에서 사용해도 안전)
· Service Role Key: 마스터키 (절대 공개금지)
예시: eyJhbGciOiJIUzI1...
사용위치: .env.local / Cloudflare
.env 파일 (환경변수 보관함)
비밀키나 서버 주소(URL)를 코드 안에 직접 적지 않고, '비밀 자금성 금고'처럼 텍스트 파일에 따로 모아두는 곳입니다.
파일명: .env.local
Git 차단: .gitignore 필수

안티그래비티 CLI로 자연어 DB 제어하기 (테이블 생성/수정/삭제 & CRUD 세팅)

안티그래비티 CLI에게 **"products 테이블에 brand 컬럼 추가해줘"**, **"수량 0개인 제품 지워줘"**처럼 말하면 알아서 Supabase DB에 반영되도록 세팅하는 3가지 방법입니다.

방법 1. 가장 스마트함 Supabase MCP Server 연동 세팅

안티그래비티 MCP 설정 파일에 Supabase 토큰을 등록하여 에이전트가 직접 Supabase DB 툴을 전권 제어하는 방식입니다.

설정 파일 위치: ~/.gemini/antigravity-cli/mcp.json
mcp.json 
{
  "mcpServers": {
    "supabase": {
      "command": "npx",
      "args": ["-y", "@supabase/mcp-server-supabase@latest"],
      "env": {
        "SUPABASE_ACCESS_TOKEN": "sbp_발급받은_액세스_토큰",
        "SUPABASE_PROJECT_REF": "내_프로젝트_REF_코드"
      }
    }
  }
}
MCP 세팅 후 사용할 수 있는 자연어 프롬프트 예시
· 💬 "products 테이블에 brand (문자열) 컬럼 새로 추가해줘"
· 💬 "orders 테이블 만들고 주문일자, 고객명, 총금액 컬럼 세팅해줘"
· 💬 "재고 수량이 0인 모든 상품 삭제해줘"
방법 2. 가장 간단함 DATABASE_URL (Direct Connection) `.env` 세팅

Supabase Direct PostgreSQL 연결 문자열을 `.env`에 등록해두면 안티그래비티 CLI가 터미널 SQL 커맨드로 즉시 DB를 조작합니다.

Supabase 대시보드 → Project Settings → Database → Connection String (Direct Connection URI)
`.env` 
DATABASE_URL=postgresql://postgres:내DB비밀번호@db.abcdefg.supabase.co:5432/postgres

Phase 1: 로컬 재고관리 앱 바이브 코딩

Step 1 프롬프트 (안티그래비티 CLI 입력용)
Vite + React + Tailwind CSS 기반의 실시간 재고관리(Inventory Management) 앱을 생성해줘. [필수 구현 기능] 1. 재고 목록 대시보드 (제품명, SKU 코드, 카테고리, 수량, 단가, 총 재고금액, 안전재고 수량) 2. 재고 입출고(Inbound / Outbound) 기록 modal 및 수량 자동 계산 3. 재고 부족 알림 경고 (안전재고 미만 제품 빨간색 하이라이트) 4. SKU 코드/제품명 실시간 검색 및 카테고리 필터링 5. 다크 모드가 적용된 대시보드 UI (Lucide Icons 포함) 터미널 명령어를 직접 실행해서 프로젝트 폴더 세팅과 패키지 설치까지 모두 마쳐줘.
8

Phase 2: Supabase 연동 & SQL 자동 구축

Step 2 프롬프트 (안티그래비티 CLI 입력용)
현재 재고관리 앱을 Supabase 백엔드와 연동해줘. 1. @supabase/supabase-js 라이브러리를 설치해줘. 2. Supabase DB 구축을 위한 SQL 스크립트(`supabase_schema.sql`)를 프로젝트 루트에 생성해줘: - `products` 테이블: id, sku, name, category, quantity, min_quantity, unit_price, created_at - `inventory_logs` 테이블: id, product_id, type('IN'|'OUT'), amount, reason, created_at - Row Level Security(RLS) 정책 추가 (익명 읽기/쓰기 허용 정책) 3. `.env.local` 파일에 VITE_SUPABASE_URL 및 VITE_SUPABASE_ANON_KEY 템플릿 생성해줘. 4. 기존 로컬 mock 데이터를 Supabase 연동 코드(async fetch/insert/update)로 교체해줘. 5. Supabase Realtime 구독을 추가해서 다른 클라이언트가 재고 변경 시 즉시 화면에 반영되게 해줘.
9

Phase 3: Cloudflare Pages 원클릭 배포

Step 3 프롬프트 (안티그래비티 CLI 입력용)
이 프로젝트를 Cloudflare Pages에 프로덕션 배포해줘. 1. 먼저 `npm run build`를 실행해서 빌드 오류가 없는지 검증해줘. (오류가 있다면 스스로 수정해줘) 2. `npx wrangler pages deploy ./dist --project-name=my-inventory-vibe` 명령을 실행해줘. 3. 배포 성공 후 생성된 Cloudflare Pages 라이브 URL을 출력하고, 필요사항을 점검해줘.
