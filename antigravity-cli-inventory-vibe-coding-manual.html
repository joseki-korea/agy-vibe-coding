처음 나오는 필수 용어 쉬운 말 정리

CLI (터미널)

마우스로 버튼을 누르는 대신 텍스트 글자로 명령어를 입력하여 컴퓨터를 실행하는 창입니다.

DB (데이터베이스)

웹 사이트를 새로고침하거나 브라우저를 꺼도 재고 수량이나 주문 내역이 사라지지 않게 보관하는 클라우드 엑셀표입니다.

RLS (Row Level Security)

아무나 내 데이터베이스에 접근해서 데이터를 지우거나 수정하지 못하도록 막아주는 출입 보안 규칙입니다.

배포 (Deployment)

내 컴퓨터에서만 보이던 웹 앱을 전 세계 누구나 접속할 수 있는 실제 인터넷 주소(`https://...`)로 인터넷에 공개하는 작업입니다.

Step 1. Antigravity CLI 실행 및 로그인

단계별 가이드 Antigravity CLI 가입 및 로그인
1. 이번 단계에서 할 일

내 컴퓨터 터미널에서 Antigravity CLI 패키지를 실행하고 Google 계정으로 로그인합니다.

2. 실행할 명령어 (운영체제별)
[macOS / Linux]
Terminal
npm install -g agy
agy login
[Windows - PowerShell 관리자 권한]
PowerShell
npm install -g agy
agy login
3. 정상적으로 완료된 성공 기준

웹 브라우저가 열리며 "Successfully logged in to Antigravity AI Engine" 메시지가 뜨고, 터미널에 질문을 입력할 수 있는 상태가 됩니다.

4. 오류 발생 시 해결 방법

· command not found: agy 오류 발생 시: Node.js가 정상 설치되어 있는지 확인 후 npm install -g agy를 재실행합니다.

Step 2. 재고관리 화면 만들기 (로컬 실행)

단계별 가이드 로컬 React UI 생성 및 테스트
1. 이번 단계에서 할 일

작업 폴더(`vibe-inventory`)를 생성하고 Vite + React 기반의 대시보드 화면을 생성합니다.

2. Antigravity CLI에 입력할 프롬프트
현재 폴더에 Vite + React 기반의 재고관리 대시보드 앱을 생성해줘. 1. 재고 목록 대시보드 (제품명, SKU 코드, 카테고리, 수량, 단가) 2. 재고 부족 알림 (안전재고 미만 시 빨간색 표시) 3. 실시간 검색 및 카테고리 필터 기능 4. npm run dev 로컬 서버 구동 명령어까지 확인해줘!
3. 정상 완료 성공 기준

터미널에서 npm run dev 실행 시 `http://localhost:5173` 주소가 나타나고 웹 브라우저에서 재고 대시보드가 열립니다.

5

Step 3. Supabase 데이터베이스 연동 & 보안 설정

단계별 가이드 Supabase 연동 및 Publishable Key 설정
1. 이번 단계에서 할 일

Supabase 프로젝트를 생성하고, 데이터베이스 테이블(`test_inventory_items`) 구축 및 `.env.local` 키 설정을 진행합니다.

중요 보안 경고 (Publishable vs Secret Key)
· **Publishable Key (Anon Key)**: 브라우저에 포함되어도 안전한 공개 키입니다.
· **Secret Key (Service Role Key)**: 모든 데이터 변경 권한을 가진 마스터키이므로 **절대 웹 브라우저나 `.env.local` 코드에 포함해서는 안 됩니다!**
2. CLI 프롬프트 입력
현재 프로젝트를 Supabase 백엔드와 연동해줘. 1. @supabase/supabase-js 라이브러리 설치 2. test_inventory_schema.sql 파일 생성 및 RLS 보안 정책 추가 3. .env.local 파일 생성 (VITE_SUPABASE_URL 및 VITE_SUPABASE_ANON_KEY 세팅) 4. 소스 코드에서 Supabase 데이터를 async/await 로 동기화하도록 업데이트해줘!
3. 성공 기준

앱에서 새 상품을 추가하거나 입출고 시 Supabase 대시보드의 Table Editor에 실제 데이터가 실시간 저장됩니다.

Step 4. Cloudflare Pages 프로덕션 무료 배포

단계별 가이드 Cloudflare Pages 4단계 배포
Terminal
# 1. Cloudflare CLI 로그인
npx wrangler login

# 2. 빌드 검증 (dist 폴더 생성)
npm run build

# 3. 프로젝트 생성 (최초 1회)
npx wrangler pages project create vibe-inventory --production-branch main

# 4. 배포 실행
npx wrangler pages deploy ./dist --project-name=vibe-inventory
성공 기준

터미널 마지막 줄에 "✨ Deployment complete! Take a peek over at https://vibe-inventory.pages.dev" 주소가 출력되며 모바일 및 PC에서 접속이 잘 됩니다.

최종 기능 및 보안 점검 체크리스트

[ ] 재고 목록 조회, 검색, 카테고리 필터링이 잘 작동한다.
[ ] 제품 추가 및 입출고 변경 결과가 Supabase DB에 실시간 저장된다.
[ ] 브라우저를 새로고침해도 데이터가 유실되지 않고 유지된다.
[ ] RLS 보안 정책이 활성화되어 있고 마스터키(Secret Key)가 코드에 포함되지 않았다.
[ ] `.env.local` 파일이 `.gitignore`에 등록되어 GitHub에 유출되지 않았다.
[ ] Cloudflare Pages 라이브 주소가 PC 및 모바일 브라우저에서 잘 열린다.
[ ] 서브페이지를 새로고침해도 404 Not Found 에러가 발생하지 않는다 (`public/_redirects`).
⚠️ 본 프로젝트는 학습 및 포트폴리오용 예제입니다. 실제 고객 개인정보나 기업의 대규모 실시간 재고에 사용할 때에는 전문가의 별도 보안 검토를 권장합니다.
