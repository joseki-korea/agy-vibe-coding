# UI Components Asset Index — agy-vibe-coding

## 1. 개요
본 디렉토리는 `agy-vibe-coding` 레포지토리의 재사용 가능한 UI 컴포넌트, 스타일시트 및 템플릿 소스코드를 관리합니다.

## 2. 추적 원칙
- UI 소스코드(`*.jsx`, `*.tsx`, `*.js`, `*.css`, `*.html`, `*.vue`)는 Git에 정상 추적됩니다.
- 바이너리/미디어 파일(`*.png`, `*.jpg`, `*.zip` 등)은 `.gitignore` 규칙에 따라 Git 추적에서 제외되고 Drive로 분리 연동됩니다.
