# Codex Terra Role Definition — agy-vibe-coding

## 1. 역할 정의 (Role Overview)
Codex Terra는 프로젝트의 백엔드 및 핵심 계산 로직을 구현하는 전담 작업 세션입니다.

## 2. 주요 책임 (Responsibilities)
- 핵심 비즈니스 로직, API 라우터 및 데이터 알고리즘 구현.
- 데이터 모델링, 스키마 마이그레이션 및 비즈니스 데이터 무결성 검증.
- 단위 테스트 작성 및 계산 로직 엣지 케이스 검증.
