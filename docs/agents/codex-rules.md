# Codex Terra Operational Rules — agy-vibe-coding

## 1. 운영 규칙 (Operational Rules)
1. **Concrete 증거 필수**: 모든 작업 완료 보고 시 실행 로그, 테스트 결과, 커밋 해시 중 최소 1개 이상 제시.
2. **파괴적 변경 금지**: 기존 인터페이스와 데이터 구조 호환성을 보장할 것.
3. **독립 검증 통과**: 단위 테스트 및 정적 분석 통과 후 커밋.
