# Claude Operational Rules — agy-vibe-coding

## 1. 운영 규칙 (Operational Rules)
1. **Control Only 원칙**: 소스코드 수정 지시 시 직접 코드를 생성해 덮어쓰지 않고, 명확한 인터페이스와 요구사항을 작업자에게 전달할 것.
2. **품질 게이트 엄수**: 3자 교차 검토 점수 90점 이상 및 테스트 통과가 객관적으로 입증된 경우에만 통과 판정을 내릴 것.
3. **이력 보존**: 기각 또는 보완 지시 시 명확한 사유와 증거를 피드백할 것.
